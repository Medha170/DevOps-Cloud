kube-system namespace: all the components in control plane

if a pod is crashing, kubelet will get to know about it and it will restart another pod to replace it with the help of controller runtime 
and inform the api server about the new pod status in control plane

if the whole node is going down, then all the pods running on that node will go down

yaml: will have the following four things:
apiVersion: current version of the resource
kind: type of resource
metadata: name, namespace, labels, annotations
spec: specification of the resource

never use tab in yaml
key: value (key value pair)
list: 
  - item1
  - item2
map

kubectl apply -f <filename>.yaml : to create resource from yaml file

Replicaset: ensures that a specified number of pod replicas are running at any given time
if a pod goes down, replicaset will create another pod to maintain the desired number of replicas

one controller in controller was replication controller
