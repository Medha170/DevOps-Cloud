Docker Networking
IP Address: unique rootable address given to a device ona network which follows the IP protocol for communitaion.
Ethernet Card: hardware component that connects a computer to a network using Ethernet protocol. and connect it to a network switch
Ethernet Cable: hardware to connect devices to network switches.
A device can have mutiple IP addresses if it has multiple network interfaces.
Network switch: it follows ARP protocol to map IP addresses to MAC addresses and forwards data packets to the correct device on a local network. it broadcasts ARP requests to all devices on the local network to find the MAC address associated with a specific IP address.
-Default Route: if all the other routes do not match, the default route is used to forward the packet.
Gateway: a device that connects two different types of networks and routes traffic between them.
Subnet Mask: a 32-bit number that divides an IP address into network and host portions, determining which part of the address identifies the network and which part identifies the device on that network.
192.168.10.0/24: 24 is subnet mask, 32-24=8 bits for host portion, 2^8-2=254 IPs
