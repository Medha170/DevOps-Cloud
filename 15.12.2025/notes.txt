Step 2: disable swap
swapspace: It is a portion of a hard drive that is used as virtual memory when the physical RAM is full. It allows the system to continue functioning by temporarily moving inactive pages of memory to the swap space on the hard drive. This helps to free up RAM for active processes and can improve overall system performance.
Why disable swap for k8s?
Kubernetes relies on the availability of memory resources to effectively manage and schedule containers. When swap is enabled, the operating system may move inactive memory pages to swap space, which can lead to performance degradation and instability for applications running in containers. Disabling swap ensures that Kubernetes has accurate visibility into the available memory resources, allowing it to make informed decisions about resource allocation and scheduling.
