SCA vs SAST:
SCA: Software Composition Analysis - focuses on open source components and their vulnerabilities.
SAST: Static Application Security Testing - analyzes source code for security vulnerabilities.

- Who does this? DevOps engineer, DevSecOps engineer (but according to devops principle, there should not be any separate role, instead developer should collaborate with each other to ensure security is integrated throughout the development process)
- What are different testing? Unit Testing, Integration Testing, etc
- What is the advantage of DevOps?

        automation of processes
        not compromise on quality

DevSecOps vs CyberSeurity engineer:
DevSecOps engineer: Integrates security practices into the DevOps process, focusing on automation and collaboration to ensure secure software delivery.
CyberSecurity engineer: Focuses on protecting systems, networks, and data from cyber threats through monitoring, incident response, and implementing security measures.
